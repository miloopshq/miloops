# MILOOPS brand pack

The final MILO CRT mascot, rendered at exact pixel sizes. Source and re-rendering: [`packages/milo-avatar`](../packages/milo-avatar) (`npm run capture`).

| File | Size | Use it for |
| --- | --- | --- |
| `github-org-avatar.png` | 1000×1000 | GitHub organization avatar |
| `github-social-preview.png` | 1280×640 | GitHub repository social preview (Settings → Social preview) |
| `miloops-banner.gif` | 1280×640 | Animated README banner: MILO loops watching → processing → transmitting → decision waiting (still platforms use the PNGs) |
| `og-image-1200x630.png` | 1200×630 | Open Graph / Twitter card image for miloops.vercel.app and link previews |
| `x-avatar-400.png` | 400×400 | X (Twitter) profile picture |
| `x-header-1500x500.png` | 1500×500 | X (Twitter) header banner |
| `wordmark-lockup.png` | 960×240 | Logo lockup (mini MILO + MILO/OPS) for docs, decks and press |
| `linkedin-discord-avatar-512.png` | 512×512 | LinkedIn and Discord avatars |
| `slack-icon-512.png` | 512×512 | Slack app icon; also the landing's apple-touch icon |
| `favicon-32.png` | 32×32 | Browser favicon |
| `favicon-64.png` | 64×64 | High-DPI browser favicon |

[`miloops-social-kit.zip`](miloops-social-kit.zip) bundles every file above (prefixed `milo-final-`) plus the `social-kit-overview.png` contact sheet in one download.

The landing ([miloops-landing](https://github.com/teamtrailhq/teamtrail-landing)) serves its own copies of the favicons, OG image and Slack icon from `public/media/brand/`.
